# Sicherheit

Meldungen für eingeloggte Nutzer werden ausschließlich serverseitig nach Empfänger-ID gefiltert. REST-Schreibzugriffe benötigen eine gültige WordPress-Anmeldung und Nonce; Backend-Aktionen benötigen zusätzlich `manage_options`. Bitte keine Kunden- oder Zugangsdaten in Issues veröffentlichen.
